# PRD：AI 热点日报 v6（2026-10-10，已确认）

> 状态：**已确认**（2026-10-10，qiao 授权贾维斯拍板，第 8 节的四个问题均按产品建议执行）。各功能按里程碑拆分 Issue。
> 基线：现状版 v5（线上 https://ai-daily.qiao-ai-daily.workers.dev ）。

## 1. 目标
一句话定位：**每天 5 分钟，用中文看懂 X 上的 AI 圈**。要可信、精美、方便转发。
- **G1 精美统一**：有统一的品牌（Logo / VI）和视觉规范，所有页面和分享图都遵守，克制、不“AI 味”。
- **G2 读得更快**：打开首页 30 秒内就能知道今天最重要的三件事。
- **G3 看得更深**：每个话题都能看到来龙去脉，包括持续了几天、热度怎么变化、和哪些话题有关。
- **G4 愿意转发**：每天一张、每个话题一张的分享图，发到微信或 X 都好看。
- **G5 工程可维护**：标准、主流的前后端工程结构，有完整的自动化测试，能安全迭代。
- **延续 v5 的原则**：数据真实不编造，Cloudflare 免费额度内运行，每日更新不需要重新部署。

## 2. 用户与场景
| 用户 | 场景 |
|---|---|
| qiao（主要） | 早上在手机上看当天日报；在电脑上回看、搜索；把好内容转发出去 |
| 朋友 / 同事（次要） | 从分享的图片或链接进来，只读浏览 |

## 3. 功能需求

### F1 首页改版（P0）
- 顶部是日期切换和“**今日三件事**”：取当天 JSON 中 `highlights` 的前 3 条，**不改每日数据格式**。
- 话题卡片带标记：当天首次出现的话题标“新”；连续出现 N（≥2）天的话题标“持续热议 N 天”（按 `topics` 跨日匹配）。
- 卡片显示热度条（0–100）、机构标签、分类；保留分类筛选、历史日期、搜索、收藏、趋势、导出、主题切换这些 v5 已有的功能。
- **验收**：手机 390px 首屏能看到三件事和第一张卡片；4 种组合（手机/电脑 × 浅色/深色）都符合视觉规范；v5 的功能全部可用。

### F2 话题详情页（P0）
- 每个话题有独立 URL，可以直接打开、刷新和分享。
- 内容依次是标题、摘要、为什么重要、热度走势、全部 X 原帖（含译文和互动数）、新闻链接、数据说明、关联话题（同机构或同 `topics` 的历史话题，最多 5 个）。
- 热度走势只用真实的每日 `heat`；只有 1 天数据时显示“首次出现”，**不画假走势**。
- **验收**：用 `tests/fixtures` 的多天数据，走势点数、数值和数据库一致；单日数据时显示空状态。

### F3 分享图（P1）
- **每日卡片**：竖版 3:4，大号日期、今日三件事、Logo 和网址（可带二维码）。
- **话题卡片**：标题、摘要节选、热度、日期、Logo。
- 由服务端生成 **PNG**，作为页面的 og:image（用于 X 等平台的链接预览）；页面上有“保存图片”按钮，下载的是同一张图。
- 每日卡片一天只生成一次，话题卡片第一次访问时生成，之后都走缓存。
- **验收**：尺寸固定；中文不缺字、不出现方框；X 的链接预览能显示图片；手机能保存图片；只做浅色一版。

### F4 关注（P2）
- 可以关注 X 账号、机构标签或关键词；首页高亮“我关注的”话题，并提供“只看关注”筛选。
- **存在本机浏览器（localStorage）里，不登录、不上传**，换设备不同步。
- **验收**：关注、取消关注、刷新后保持；没有关注任何内容时有引导性的空状态。

### F5 周报（P2）
- 每周汇总一周 Top 10 和反复出现的话题，由已有数据**实时计算**，不新增采集。复用分享图的版式。
- **验收**：周报数字可以从每日数据复算出来。

## 3.1 信息架构（与设计对齐）
- 手机底部标签栏有四个：今日、往期、搜索、我的。往期页顶部可以切换“趋势”和“周报”；“我的”里放收藏和关注。电脑端用侧边导航，结构与手机一致。
- 字体：网页优先用系统字体，其他设备回退到思源黑体 + Inter；分享图一律嵌入思源黑体 + Inter 的子集。

## 4. 品牌与视觉要求（交给设计，由 qiao 拍板）
- 先定 Logo / VI 和视觉规范，再出 UI 页面设计；所有页面和分享图共用一套规范（颜色、字号、间距、组件）。
- 已定方向：现代、柔和的苹果风格，主色是紫色（浅色模式 `#7D5AF0`，深色模式 `#A88BFF`，紫色文字用 `#6440D6`），Logo 用方案 B。详细规范以 `docs/design/` 为准（PR #5）。
- 克制、不“AI 味”：不用紫蓝渐变、发光、满屏 emoji、大圆角胶囊这类套路。
- 手机优先；浅色和深色两套主题都要完整设计。

## 5. 工程要求（非功能）
- 前端：Vite + React + TypeScript + Tailwind 4。后端：Hono 跑在 Cloudflare Workers 上。数据库沿用 D1。代码组织成 monorepo，前后端共用类型和数据 schema。
- **兼容性红线**：现有 API 的路径和返回格式不变；`daily.sh`、`json2sql`、D1 表结构和每日 JSON 格式都不变。每天 8:50 的数据更新不能断。
- 参数统一校验，非法输入一律返回 400（顺带修掉已知的 6 个接口 bug）。
- 测试：单元测试、组件测试、API 黑盒测试、端到端测试，以及 4 种组合（手机/电脑 × 浅色/深色）的截图对比，全部纳入本地 CI 并且都要通过。
- 部署：生产和预览分成两套环境；发布前备份；能在几分钟内回滚。坚持在 Cloudflare 免费额度内运行，新增任何付费资源都需要 qiao 批准。
- 性能：手机 4G 网络下，首页首屏 2 秒内出现。

## 6. 非目标（v6 不做）
- 账号体系和登录、个人云端收藏、多设备同步。
- 评论、点赞等社交功能，以及实时推送。
- 新的数据源，或者修改每日采集流程。

## 7. 里程碑
1. **M0 定稿**：PRD 签字（关卡 1），Logo / VI、视觉规范和 UI 设计选定（关卡 2）。
2. **M1 工程重构**：搭新的工程结构，功能和 v5 保持一致；修掉 6 个 bug；建好预览环境。
3. **M2 首页改版 + 详情页**（F1、F2）。
4. **M3 分享图**（F3）。
5. **M4 关注 + 周报**（F4、F5）。
每个里程碑都单独走 PR、测试、qiao 批准、部署。

## 8. 已确认的决定（2026-10-10）
1. 范围和优先级按第 3 节执行：P0 是 F1 首页改版和 F2 话题详情页，P1 是 F3 分享图，P2 是 F4 关注和 F5 周报。
2. 关注功能只做本机版（存在浏览器 localStorage 里，不登录）。
3. 分享图只做浅色一版；网页本身同时支持浅色和深色。
4. 坚持用 Cloudflare 免费额度，不升级 Workers 付费版。实时生成图片超出限制时，改为在每天 8:50 更新数据时预先生成。
