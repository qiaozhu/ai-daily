# Roadmap / Backlog

> 想法池，未排期。要做的条目请开 Issue（type:feature，status:needs-prd），由产品 bot 写 PRD，负责人签字后进入设计/开发。

## 候选
- **显示名入库**：发帖人显示名目前写死在 `public/app.js` 的 `NAMES` 表，新账号只显示 @handle。方案：posts 表加 `name` 列（迁移 0002）+ json2sql 写入 + API 返回，前端优先用 API 字段。
- **定时任务自动化**：每日采集 → 写 JSON → `daily.sh` → 通知 qiao，目前由 bot 手动执行；做成可靠的定时流程（失败告警、缺日提醒）。
- **自定义域名**：绑定自有域名到 Worker（需要 Cloudflare 上的 zone）。
- **收藏鉴权 / 个人收藏**：收藏目前全站共享、无登录；可选 Cloudflare Access、简单口令或按设备匿名 ID。
- **今日要点去留**：数据仍有 `highlights`，v3 起 UI 移除；可考虑在日报顶部做可折叠摘要或用于推送文案。
- **推送**：每日把地址/要点发到邮箱或 IM（需负责人确认渠道）。
- **数据快照同步**：每日 JSON 自动 PR 到仓库 `data/`。
- **E2E 进 CI**：在 CI 里起 `wrangler dev --local` + 无头 Chrome 跑 `tests/ui-v2.js`（目前只在本地/上线后跑）。
- **测试不写生产**：UI 测试的收藏用例会在目标站点加一条再删掉；为线上验证提供只读模式或测试专用库。
- **趋势增强**：需要积累多天数据后再做话题时间线、热度曲线。
- **分享卡片**：单条话题的独立 URL / OG 图。
- **可访问性**：键盘导航、对比度检查、屏幕阅读器标签。
